# 🏫 RAVEN SYSTEMS — School Management Platform

A complete, full-stack school management system built with Flask. RAVEN SYSTEMS enables schools to manage students, teachers, subjects, marks, reports, announcements, and authentication — all in one centralized platform.

---

## 📖 About RAVEN SYSTEMS

RAVEN SYSTEMS is a comprehensive school management platform designed for educational institutions. It provides role-based access for students, teachers, and administrators with a clean, responsive interface.

### Key Functionalities

- **Student Management** – Register, update, and manage student profiles with class, combination, and subject tracking.
- **Teacher Management** – Assign teachers to subjects and classes.
- **Subject Management** – Create subjects with paper-specific maximum marks.
- **Marks & Results** – Record and calculate student marks, averages, points, and positions per term.
- **Reports** – Generate and store student reports with file uploads.
- **Announcements** – Broadcast announcements to all users or specific targets.
- **Alerts** – Send targeted alerts to individual students.
- **Authentication** – Secure JWT-based login with password hashing.
- **Role-Based Access** – Different dashboards for students, teachers, and admins.
- **PWA Support** – Installable as a Progressive Web App for mobile use.
- **Responsive Design** – Optimized for desktop, tablet, and mobile.

##  Tech Stack

| Layer | Technology |
|-------|------------|
| **Backend** | Flask (Python 3.8+) |
| **Frontend** | HTML5, CSS3, Vanilla JavaScript |
| **Database** | SQLite (development) / PostgreSQL (production) |
| **Authentication** | JWT (PyJWT), Werkzeug (password hashing) |
| **Hosting** | Render (backend) + GitHub Pages (frontend) |
